# BillBuddy Frontend

BillBuddy is a full-stack expense sharing application inspired by Splitwise, designed to help users manage personal and shared expenses, track debts, and settle balances within groups.

This repository contains the frontend application built with React and TypeScript.

## Features

### Authentication

- User Registration
- User Login
- JWT Session Management
- Protected Routes

### Dashboard

- Expense Statistics
- Category Analytics
- Monthly Expense Trends
- Recent Activity
- Group Spending Overview

### Expense Management

- Personal Expenses
- Shared Group Expenses
- Expense Categories
- Expense Deletion

### Group Management

- Create Groups
- Invite Members
- Manage Member Roles
- Debt Tracking
- Settlements

### User Experience

- Responsive Design
- Toast Notifications
- Interactive Dialogs
- Profile Management
- Image Uploads

## Tech Stack

- React
- TypeScript
- Redux Toolkit
- React Router
- Axios
- Tailwind CSS
- shadcn/ui
- Recharts

## Installation

### Configure Environment

Create a `.env` file:

```env
VITE_API_URL=<backend_api_url>
```

### Install Dependencies

```bash
npm install
```

### Run Application

```bash
npm run dev
```
The application will be available according to your local Vite configuration.
